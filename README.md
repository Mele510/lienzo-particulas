# Lienzo de Partículas 🎨✨

Una animación sencilla hecha con **HTML5 Canvas** y JavaScript puro (sin librerías externas). Muestra un lienzo lleno de partículas flotantes que reaccionan al movimiento del mouse.

## Archivos

- `index.html` — estructura de la página y el `<canvas>`.
- `particulas.js` — la lógica de la animación (creación, movimiento y dibujo de las partículas).

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
